# 🐞 Найденные расхождения с описанием метода

Метод: `POST /api/v1/de/organization` (создание организации).
Инструмент: Postman. Окружение: тестовый стенд из задания.

Для каждой проблемы указан запрос из коллекции, ожидаемый и фактический результат.

---

## 🐛 BUG-1. Поле `name` принимает число вместо строки

**📬 Запрос в коллекции:** папка `01 name`, `name: число вместо строки → 400`.

**👣 Шаги:**
1. Отправить `POST /api/v1/de/organization` с корректным токеном.
2. В теле передать `"name": 123` (число без кавычек), остальные поля корректные, ИНН уникальный.

**✅ Ожидаемый результат:** `400 Bad Request`. По описанию метода `name` имеет тип String.

**❌ Фактический результат:** `200 OK`, организация создана, в ответе возвращён `id`.

**⚠️ Severity:** низкая.
**⏱️ Priority:** низкая.

---

## 🐛 BUG-3. Неверный токен приводит к 500 вместо 401

**📬 Запрос в коллекции:** папка `10 Авторизация`, `auth: неверный токен → 401`.

**👣 Шаги:**
1. Отправить `POST /api/v1/de/organization` с корректным телом.
2. В заголовке `Authorization` указать `Bearer abc123`.

**✅ Ожидаемый результат:** `401 Unauthorized`, сообщение о том, что пользователь не авторизован.

**❌ Фактический результат:** `500 Internal Server Error`. В теле ответа: `status: 500`, `error: Internal Server Error`.

**💬 Комментарий:** 500 означает необработанную ошибку на сервере. Токен передан клиентом неверно, поэтому должен быть код 4xx.

**⚠️ Severity:** средняя.
**⏱️ Priority:** средняя.

---

## 🐛 BUG-4. Неподдерживаемый метод GET приводит к 500 вместо 405

**📬 Запрос в коллекции:** папка `12 Тело запроса и метод`, `method: GET вместо POST → 405`.

**👣 Шаги:**
1. Отправить `GET /api/v1/de/organization` с корректным токеном.

**✅ Ожидаемый результат:** `405 Method Not Allowed`.

**❌ Фактический результат:** `500 Internal Server Error`. В теле ответа: `title: Необрабатываемая ошибка`, `detail: Request method 'GET' is not supported`.

**💬 Комментарий:** сервер определил причину (метод не поддерживается), но вернул код ошибки сервера вместо 405.

**⚠️ Severity:** средняя.
**⏱️ Priority:** средняя.
