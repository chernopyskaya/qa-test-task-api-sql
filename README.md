# 🧪 Тестовое задание QA: API (Postman) и SQL

Тестовое задание на стажировку QA-инженера из двух частей:

1. 🔌 **API.** Коллекция проверок в Postman для метода создания организации (`POST /api/v1/de/organization`).
2. 🗄️ **SQL.** Запрос к базе PostgreSQL по заказам, товарам и покупателям.

## 📊 Результаты

**🔌 API.** В ходе тестирования найдено 4 расхождения с описанием метода:

| Проверка | Ожидалось | Получено |
|---|---|---|
| `name`: число вместо строки | ✅ 400 | ❌ 200 |
| `inn`: число вместо строки | ✅ 400 | ❌ 200 |
| Неверный токен | ✅ 401 | ❌ 500 |
| GET вместо POST | ✅ 405 | ❌ 500 |

**🗄️ SQL.** Запрос возвращает одну категорию: «Смартфоны», средняя сумма 89 987,50, 4 уникальных покупателя.

## ▶️ Как запустить коллекцию

1. Получить токен: `POST {хост}/authenticate`.
2. Импортировать файл из папки `postman` в Postman (**Import**).
3. В коллекции открыть вкладку **Authorization**, выбрать **Bearer Token** и вставить токен без слова `Bearer`.
